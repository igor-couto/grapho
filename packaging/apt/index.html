Grapho apt repository

Signed Debian and Ubuntu packages for Grapho, a quiet, local-first document editor. Supports amd64 and arm64.

Add the signing key and the repository:

curl -fsSL https://igor-couto.github.io/grapho/key.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/grapho.gpg

echo "deb [signed-by=/etc/apt/keyrings/grapho.gpg] \
https://igor-couto.github.io/grapho stable main" \
  | sudo tee /etc/apt/sources.list.d/grapho.list

sudo apt update
sudo apt install grapho

Then run grapho and open http://127.0.0.1:25265.

The key is also published with every release as release-signing-key.asc. Verify its fingerprint out of band.
