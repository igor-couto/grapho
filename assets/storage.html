    Any folder works: a local one, a network share, or a Google Drive, OneDrive, or Dropbox folder that its desktop app keeps in sync. Documents are copied there now and kept in step after every save. Removing a backup never deletes the files already there.

    Grapho runs your OpenSSH sftp client, so the keys, agent, and known_hosts you already use apply. Passwords are never stored: use a key file, or a key loaded in your agent. The first connection remembers the server's host key.

    Create a Desktop-app OAuth client in your Google Cloud project, enable the Drive API, and keep the drive.file scope. Grapho sends the browser to Google's consent page, then back to 127.0.0.1. The refresh token is kept in a separate owner-only file beside Grapho's settings, never in the data folder, and only files Grapho creates are accessible.
